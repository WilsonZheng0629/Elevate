# Elevate

Elevate is a sports performance analytics dashboard that helps volleyball athletes understand how training, sleep, soreness, and recovery affect vertical jump performance.

The goal is not to track volleyball match stats. The goal is to help athletes make smarter training decisions using data.

## MVP

Elevate will answer:

- Am I improving?
- What workouts seem connected to better vertical jump performance?
- Does sleep affect my performance?
- Does soreness predict lower performance?
- Am I overtraining?
- Which training blocks produce the biggest gains?
- Should I train hard, train light, or recover?

## Version 1 Features

- Athlete profile
- Daily wellness tracking
- Training session tracking
- Exercise-level workout tracking
- Vertical jump performance testing
- Training block comparison
- Readiness score
- Training load analysis
- Sleep and soreness analysis
- Streamlit dashboard
- Rule-based training recommendations

## Not Included in Version 1

- Volleyball match stat tracking
- Team dashboard
- Login system
- Mobile app
- Computer vision
- Wearable integration
- Machine learning model
- Automatic workout generator
